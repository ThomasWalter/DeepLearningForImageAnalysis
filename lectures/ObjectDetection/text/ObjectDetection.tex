\begin{frame}{Classification, segmentation and detection}
\begin{itemize}
	\item Image Classification: assign a label to each image. 
	\item Semantic image Segmentation: partition the image, i.e. assign a label to each pixel.   
	\item Object detection: detect instances of semantic objects of certain classes in images \cite{Ren2017, Zhao2019}.
	\item Object detection has thus two components:
	\begin{itemize}
		\item \textit{Object localization:} to determine where objects are located in a given image
		\item \textit{Object classification:} which category each object belongs to
	\end{itemize}
   \item (Multiple) instance Segmentation: combines the objectives of object detection and segmentation.
\end{itemize}
\end{frame}


\begin{frame}{Object Detection: Challenges}
\begin{itemize}
   \item Multiple outputs: Need to output variable numbers of objects per image
   \item Multiple types of output: object class and the bounding box of the object (location and extension)
   \item Computational requirement: detection often needs to be very fast, but involves many predictions.
\end{itemize}
\end{frame}

\end{tikzpicture}
\end{figure}
\vspace{-.3cm}
\begin{equation*}
IoU(A,B) = \frac{|A\cap B|}{|A\cup B|} \in [0,1]
\end{equation*}
\begin{itemize}
  \item Measures how well two boxes (or masks) overlap.
  \item Scale-invariant: the same shift (in number of pixels) costs more for a small box than for a large one.
  \item Used everywhere in detection:
  \begin{itemize}
    \item Evaluation: a prediction counts as correct if $IoU \geq$ threshold (often 0.5).
    \item Training: assigning ground truth to predictions.
    \item Post-processing to remove false detections. 
  \end{itemize}
\end{itemize}
\end{frame}

\begin{figure}[htb]

  \draw[arr, dashed] (assign) -- (pred);
\end{tikzpicture}
\end{figure}
\vspace{-.2cm}
\small
Every detector has 4 ingredients:
\begin{enumerate}
  \item \textbf{Candidates:} proposition of boxes potentially containing objects (region proposals, anchor boxes, grid cells, $\ldots$)
  \item \textbf{Assignment:} during training, which candidate should predict which ground-truth object? (IoU with the ground truth, cell containing the object center, $\ldots$)
  \item \textbf{Prediction and loss:} for each candidate, a class (classification loss) and a box, usually as offsets relative to the candidate regions (regression loss).
  \item \textbf{Post-processing:} removal of duplicate detections (non-maximum suppression).
\end{enumerate}
\end{frame}

\begin{frame}{Early approaches: the sliding window approach}
\begin{figure}[htb]
   \centering
   \includegraphics[width=0.8\textwidth]{../graphics/mitosis_detection.pdf}
   \caption{Mitosis detection in stained tissue sections \cite{Ciresan2013}.}

\begin{itemize}
\item Approach was the winner of a mitosis detection challenge \cite{Ciresan2013}. 
\item Fixed size sliding window approach: each crop is presented to a CNN.
\item The posterior probability is stored as an image value.
\item Local maxima of this probability map indicate the presence of an object.
\item Special case of object detection: the size of the objects was known before.
\end{itemize}
\end{frame}

\begin{frame}{R-CNN: bounding box regression}
\begin{figure}[htb]
   \centering
   \includegraphics[width=0.8\textwidth]{../graphics/R-CNN_bb_regression.pdf}
   \caption{Bounding box regression in R-CNN}
\end{figure}
\begin{itemize}
   \item Ground-truth bounding box is defined by center $(G_x,G_y)$ and dimensions $(G_w,G_h)$: $G=(G_x,G_y,G_w,G_h)$ 
   \item Predicted bounding box: $P=(P_x,P_y,P_w,P_h)$.
   \item We wish to learn a transformation $t$ that transforms the predicted bounding box $P$ into the ground truth bounding box $G$. 
\end{itemize}

\begin{frame}{R-CNN: bounding box regression}
\begin{figure}[htb]
   \centering
   \includegraphics[width=0.8\textwidth]{../graphics/R-CNN_bb_regression.pdf}
   \caption{Bounding box regression in R-CNN}
\end{figure}
   Regression targets: 
   \begin{align}
   t_x &= \frac{G_x-P_x}{P_w}, &
   t_y &= \frac{G_y-P_y}{P_h} \nonumber \\
   t_w &= \log \frac{G_w}{P_w}, &
   t_h &= \log \frac{G_h}{P_h}
   \end{align}
\end{frame}

\begin{frame}{R-CNN: bounding box regression}
\begin{itemize}
   \item Each proposal is warped to the same input size: the network only sees positions \emph{relative} to the box (a shift of 10 px in a 50 px box looks like a shift of 100 px in a 500 px box). The targets must therefore be relative too: $t_x,t_y$ are normalized by the width and height. This also keeps the targets in a similar range for all box sizes, so that large boxes do not dominate the loss.
   \item $t_w,t_h$ are normalized and log-transformed. This leads to symmetric values for the loss (a box twice as big leads to the same loss as a box twice as small, compared to the ground truth). 
   \item At inference, we predict $(\hat{t}_x, \hat{t}_y, \hat{t}_w, \hat{t}_h)$. 
   \item From there, we obtain the refined box: 
   \begin{align}
   \hat{x} &= P_x + \hat{t}_x \cdot P_w, &
   \hat{y} &= P_y + \hat{t}_y \cdot P_h, \nonumber \\
   \hat{w} &= P_w \cdot e^{\hat{t}_w}, &
   \hat{h} &= P_h \cdot e^{\hat{t}_h}.
   \end{align}
\end{itemize}
\end{frame}

\begin{column}{0.55\textwidth}
\small
Many candidate regions are overlapping and target the same region. Thus, for each class:
\begin{enumerate}
  \item Discard boxes with a score below a minimum value.
  \item Sort the remaining boxes by score.
  \item Keep the box with the highest score.
  \item Remove all boxes with $IoU > \tau$ with this box (typically $\tau = 0.5$).
  \item Repeat 3--4 with the remaining boxes until none are left.
\end{enumerate}
\vspace{.2cm}
Each group of overlapping boxes is reduced to its most confident member.
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Non-maximum suppression: remarks}
\begin{itemize}
  \item Used by nearly all methods in this lecture: R-CNN, Fast R-CNN, Faster R-CNN (twice: in the RPN with $\tau = 0.7$, and on the final detections), YOLO.
  \item NMS is not learned: it is a post-processing step outside the network, and $\tau$ is a hyperparameter.
  \item Applied per class: a ``person'' box does not suppress an overlapping ``bicycle'' box.
  \item Important for evaluation: duplicate detections count as false positives (see later).
  \item Failure case: crowded scenes. Two true objects with large overlap (touching nuclei, people in a crowd) can lead to suppression of one of them.   
  % \item Alternatives (later more):
  % \begin{itemize}
  %   \item Soft-NMS: decrease the score of overlapping boxes instead of removing them \cite{Bodla2017}.
  %   \item Set-based detectors (DETR \cite{Carion2020}) avoid duplicates by design and need no NMS.
  % \end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{Drawbacks of R-CNN}
\begin{itemize}
\item Fixed input size for the CNN: distortion and rescaling of images is necessary.
\item Multi-stage pipeline (no end-to-end solution, which is globally optimal).
\item Training is expensive (memory and compute), mainly due to the separate feature extraction step. 
\item Computationally expensive at prediction time, as many (overlapping) regions need to be classified. 
\item Sub-optimal region proposal step.
\end{itemize} 
\end{frame}

\begin{frame}{Fast R-CNN}
\begin{figure}[htb]
   \centering
   \includegraphics[width=0.8\textwidth]{../graphics/Fast_R-CNN.pdf}
   \caption{Fast R-CNN \cite{Girshick2015}}
\end{figure}
\begin{itemize}
	\item The entire image is processed by a neural network: generation of feature maps.
	\item Regions are proposed by some algorithm (as before).
	\item To each region, a ROI pooling layer is applied. 
\end{itemize}
%\vspace{-.5cm}
\end{frame}


\begin{frame}{Fast R-CNN: ROI pooling layer}
\begin{figure}[htb]
   \centering
   \includegraphics[height=0.4\textheight]{../graphics/ROI_pooling_layer.pdf}
   \caption{ROI pooling layer in Fast R-CNN}
\end{figure}
\begin{itemize}
   \item The region is projected onto the feature map (coordinates divided by the stride).
   \item It is divided into $W \times H$ tiles (e.g. $7\times7$): $W, H$ fixed; $w, h$ arbitrary.
   \item In each tile and each channel, the maximum is calculated (max-pooling).
   \item The output (fixed size) can then be processed by dense layers. 
\end{itemize}
\end{frame}

\begin{frame}{Fast R-CNN: ROI pooling layer}
\begin{figure}[htb]
   \centering
   \includegraphics[height=0.4\textheight]{../graphics/ROI_pooling_layer.pdf}
   \caption{ROI pooling layer in Fast R-CNN}
\end{figure}
\begin{itemize}
   \item Differentiable w.r.t.\ the features: as for max-pooling, the gradient goes to the maximum of each tile. The backbone can thus be trained through the detection head.
   \item Not differentiable w.r.t.\ the candidate box coordinates: the proposal itself is not modified by training, only the regressed offsets and object classes are.
\end{itemize}
\end{frame}

\item Two outputs:
\begin{itemize}

\end{itemize}

\begin{frame}{Faster R-CNN: motivation}
\begin{itemize}
	\item Fast R-CNN solves nearly all problems of R-CNN, and is end-to-end given a set of region proposals.
	\item The problem is that we still need to make region proposals to start with (time-consuming and two-stage algorithm).
	\item Faster R-CNN \cite{Ren2017} trains a network called Region Proposal Network (RPN) to overcome this issue.
\end{itemize}
\end{frame}

\begin{frame}{YOLO: You only look once}
\begin{itemize}
\item Problem of two-stage detection systems:
\begin{itemize}
\item First: region proposals
\item Second: classification of all region proposals individually
\item Consequently: the best performing methods are slow and not applicable in real time
\end{itemize}
\item YOLO \cite{Redmon2016}: detection as a single regression problem, from the image directly to boxes and class probabilities.
\item One forward pass of the network for the whole image: 45 images/s.
\end{itemize}
\end{frame}

\begin{frame}{YOLO: principle}
\begin{figure}[htb]
   \centering
   \includegraphics[height=0.4\textheight]{../graphics/YOLO_1.pdf}
   \caption{YOLO: the image is partitioned by an $S \times S$ grid.}
\end{figure}
\begin{itemize}
   \item The image is divided into an $S \times S$ grid of cells ($S=7$).
   \item During training, a cell is always responsible for the ground truth object whose center it contains. 
   \item For each cell, we predict:
   \begin{itemize}
      \item $B$ boxes ($B=2$), each with 4 coordinates and 1 confidence score.
      \item One set of $K$ class probabilities, shared by its $B$ boxes.
   \end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{YOLO: principle}
\begin{figure}[htb]
   \centering
   \includegraphics[height=0.4\textheight]{../graphics/YOLO_2_v2.pdf}
   \caption{All boxes predicted in one forward pass (line width: confidence).}
\end{figure}
\begin{itemize}
   \item All $S \times S \times B = 98$ boxes are predicted at once.
   \item Most boxes do not contain an object; they have a low confidence score.
   \item The candidates are fixed by the grid: no region proposals, no anchors (in YOLO v1).
\end{itemize}
\end{frame}

\begin{frame}{YOLO v1: network and output}
\begin{figure}[htb]
   \centering
   \includegraphics[height=0.4\textheight]{../graphics/YOLO_Output.pdf}
   \caption{Output tensor of YOLO (illustration with 5 classes)}
\end{figure}
\begin{itemize}
   \item Input $448 \times 448$; 24 convolutional layers, then 2 fully connected layers.
   \item Output: $S \times S \times (5B + K)$. 
   \item Example: For $S=7$, $B=2$, $K=20$: $7 \times 7 \times 30 = 1470$ outputs.
   \item Because of the fully connected layers, the prediction of each cell depends on the \emph{whole} image (global context).
\end{itemize}
\end{frame}

\begin{frame}{YOLO: box coordinates and confidence}
\begin{itemize}
   \item Box coordinates:
   \begin{itemize}
      \item Center $(x, y)$: offset relative to the cell, in $[0,1]$.
      \item Width and height $(w, h)$: relative to the image size, in $[0,1]$.
      \item The network regresses $\sqrt{w}$ and $\sqrt{h}$ (to increase the contribution of smaller boxes to the loss). 
   \end{itemize}
   \item Confidence: one output per box. Its training target is
   \begin{equation*}
   Conf^{target} =
   \begin{cases}
   IoU(\hat{B}, B) & \text{if responsible for an object } B\\
   0 & \text{otherwise}
   \end{cases}
   \end{equation*}
   where $\hat{B}$ is the predicted box.
   \item At test time, the predicted confidence estimates $P(obj) \cdot IoU$. 
\end{itemize}
\end{frame}

\begin{frame}{YOLO: which box is responsible for which object?}
\begin{columns}[c]
\begin{column}{0.42\textwidth}
\begin{figure}[htb]
\centering
\begin{tikzpicture}[scale=0.62]
  \fill[orange!25] (2,2) rectangle (3,3);
  \draw[gray!60, step=1] (0,0) grid (7,7);
  \draw[gray] (0,0) rectangle (7,7);

\caption{\scriptsize Green: ground truth and its center. Red: the two boxes predicted by the orange cell; solid: responsible (best IoU), dashed: not responsible.}
\end{figure}
\end{column}
\begin{column}{0.58\textwidth}
\small
During training, for each ground-truth object:
\begin{enumerate}
   \item The cell containing the center of the object is responsible for it.
   \item Among the $B$ boxes of this cell, the one with the highest $IoU$ with the ground truth is responsible.
\end{enumerate}
\vspace{.2cm}
Consequences:
\begin{itemize}
   \item Only the responsible box learns the coordinates of this object.
   \item The $B$ boxes of a cell specialize in different shapes (similar to anchors, but learned).
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{YOLO: loss function}
%Sum of squared errors (predictions are marked with a hat):
{\small
\begin{align*}
\mathcal{L} = \; & \lambda_{coord} \sum_{\text{resp. boxes}} \left[ (\hat{x}-x)^2 + (\hat{y}-y)^2 + (\sqrt{\hat{w}}-\sqrt{w})^2 + (\sqrt{\hat{h}}-\sqrt{h})^2 \right] \\
& + \sum_{\text{resp. boxes}} \left( \widehat{Conf} - IoU(\hat{B},B) \right)^2
  + \lambda_{noobj} \sum_{\text{other boxes}} \widehat{Conf}^{\,2} \\
& + \sum_{\text{cells with object}} \; \sum_{k=1}^{K} \left( \hat{P}(C_k|obj) - p_k \right)^2
\end{align*}}
\begin{itemize}
   \item Coordinates: responsible boxes only (as in the RPN: positive anchors only).
   \item Most boxes contain no object: $\lambda_{noobj}$ needs to be low to avoid them from dominating. 
   \item $\lambda_{coord}$ increases the weight of localization.
   \item Class probabilities: only cells that contain an object. $p_k=1$ for the true class $k$ and 0 otherwise.  
\end{itemize}
\end{frame}

\begin{frame}{YOLO: inference}
\begin{figure}[htb]
   \centering
   \includegraphics[height=0.35\textheight]{../graphics/YOLO_ClassProbabilityMap.pdf}
   \caption{Class probability map}
\end{figure}
\begin{enumerate}
   \item One forward pass: 98 boxes with confidences, and class probabilities per cell.
   \item Class-specific score of each box:
   \begin{equation*}
   P(C_k|obj) \cdot Conf \approx P(C_k|obj)\, P(obj)\, IoU = P(C_k)\, IoU
   \end{equation*}
   \item Remove boxes with a low score, then NMS for each class.
\end{enumerate}
\end{frame}

\begin{frame}{YOLO: Examples}
\begin{figure}[htb]
   \centering
   \includegraphics[width=\textwidth]{../graphics/YOLO_ex.pdf}
   \caption{Examples for YOLO detections}
\end{figure}
The method is extremely fast. Localization is less precise than for Faster R-CNN.
\end{frame}

\begin{frame}{YOLO v1: limitations}
\begin{itemize}
   \item Each grid cell predicts only $B$ boxes and one class: problems with small objects that appear in groups (e.g. flocks of birds, crowds, clusters of nuclei).
   \item Coarse grid ($7 \times 7$) and no reference shapes: localization errors are the main source of errors.
   \item The loss treats errors in small and large boxes similarly, although the same error matters more for a small box. Regressing $\sqrt{w}, \sqrt{h}$ only partially compensates.
\end{itemize}
\end{frame}

\begin{frame}{CenterNet: training and inference}
\begin{itemize}
   \item \textbf{Training targets:}
   \begin{itemize}
      \item Heatmap: a Gaussian centered on each annotated object, with a width depending on the object size.
      \item Width, height and offset: learned only at the object centers (L1 loss).
   \end{itemize}
   \item Heatmap loss: focal loss (pixel-wise classification, easy background pixels are down-weighted).
   \item \textbf{Inference:}
   \begin{itemize}
      \item Local maxima of the predicted heatmaps provide the object centers
      \item Box = center $\pm$ half the predicted width and height.
      \item The local maxima replace NMS.
   \end{itemize}
   %\item Compare with the sliding window approach of \cite{Ciresan2013}: probability map and local maxima, now dense, multi-class, end-to-end, and with box sizes.
   \item Natural for point-like objects (nuclei, mitoses).
\end{itemize}

\small
Detector output: (box, class, score).
For one class, on the whole test set:
\begin{enumerate}
  \item Sort detections by decreasing confidence score.
  \item For each detection, find the unmatched ground truth with the highest IoU.
  \item If $IoU \geq 0.5$: \textbf{true positive (TP)}; this ground truth is now matched.
  \item Otherwise: \textbf{false positive (FP)}.
  \item Unmatched ground truth: \textbf{false negatives (FN)}.
\end{enumerate}
\vspace{.1cm}
Each object is matched only once: duplicates are FP (hence NMS).
\end{column}

\begin{frame}{Precision and recall}
\begin{equation*}
\text{Precision} = \frac{TP}{TP+FP}
\qquad\qquad
\text{Recall} = \frac{TP}{TP+FN}
\end{equation*}
\begin{itemize}
  \item Recall: fraction of true objects detected by the algorithm.
  \item Precision: fraction of detected objects that are true objects.
  \item There are no true negatives: the number of possible ``empty'' boxes is unbounded. Accuracy, specificity and ROC curves are therefore not used.
  \item Both depend on the score threshold:
  \begin{itemize}
    \item High threshold: few, confident detections $\rightarrow$ high precision, low recall.
    \item Low threshold: many detections $\rightarrow$ high recall, low precision.
  \end{itemize}
  \item To evaluate a detector independently of the threshold, we record precision and recall for several thresholds, providing the \textbf{precision--recall curve}.
\end{itemize}
\end{frame}

\begin{frame}{Average Precision (AP) and mAP}
\begin{itemize}
  \item \textbf{Interpolation:} the raw curve zig-zags. Precision at recall $r$ is replaced by the best precision reachable at recall $\geq r$ (upper envelope):
  \begin{equation*}
  p_{interp}(r) = \max_{\tilde{r} \geq r} p(\tilde{r})
  \end{equation*}
  \item \textbf{AP} = area under the interpolated precision--recall curve (one value per class, between 0 and 1).
  \item \textbf{mAP} (mean Average Precision) = mean of AP over all classes.
  \item AP summarizes the curve in one number, independently of the choice of a score threshold.
  %\item The training loss is computed per candidate box and is differentiable; mAP is computed on the whole test set after NMS and matching, and is not differentiable.
\end{itemize}
\end{frame}

\begin{frame}{Common variants of the metric}
\begin{itemize}
  \item \textbf{PASCAL VOC} \cite{Everingham2010}: mAP at $IoU \geq 0.5$ (often written AP$_{50}$).
  \item \textbf{COCO} \cite{Lin2014}: AP averaged over 10 IoU thresholds $0.50, 0.55, \ldots, 0.95$, written AP or AP@[.5:.95].
  \begin{itemize}
    \item Rewards precise localization, not only finding the object.
    \item Also reported: AP$_{50}$, AP$_{75}$, and AP$_S$, AP$_M$, AP$_L$ for small, medium and large objects.
    \item In COCO papers, ``AP'' already denotes the mean over classes.
  \end{itemize}
  \item \textbf{Instance segmentation}: same procedure, with IoU computed on masks instead of boxes.
  \item \textbf{Biomedical point-like objects} (mitoses, nuclei centroids): boxes are not meaningful.
  \begin{itemize}
    \item Matching by distance between centroids (e.g. within 7.5\,$\mu m$ in MIDOG \cite{Aubreville2023}).
    \item Often reported as F1 score $= \frac{2\,TP}{2\,TP + FP + FN}$ at a fixed threshold.
  \end{itemize}
\end{itemize}
\end{frame}

\begin{itemize}
\item Solving the instance segmentation problem in parallel to object classification and localization. 
\item Relatively small modification of the Faster R-CNN architecture
\item Feature sharing between tasks
\end{itemize}
\end{frame}

\begin{itemize}
\item Additional branch for segmentation, parallel to object classification and localization
\item Joint loss function (sum of localization, classification and segmentation terms)
\item Alignment of ROI by bilinear interpolation
\end{itemize}

\begin{frame}{Conclusion}
\begin{itemize}
\item Object detection is a major challenge in Computer Vision with applications in biomedical image analysis, autonomous driving, industrial applications, etc.
\item CNNs outperform most traditional methods by a large margin. 
\item Today, object detection is among the most stunning applications of Computer Vision. 
\item There are hundreds of methods, but the most important advances were achieved by R-CNN, Fast R-CNN, Faster R-CNN and YOLO. 
\item They can be combined with segmentation (Mask R-CNN). 
\end{itemize}
